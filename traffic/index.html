Funnel

Dimmed rows are events that did not exist for the whole window, so their share is measured against sessions that could never have fired them. Their bar is hatched and their drop hidden on purpose. Narrow the window to the marked date to compare them fairly.

Devices

Counted from the server's own request log — there is no analytics product, no cookie, and nothing is stored about a visitor. A session is one page load. Numbers refresh every 30 seconds and the server caches each window for 60, so the newest figure can be up to a minute and a half behind. Hits from a machine that is developing the game are not excluded, so your own testing shows up here too — on quiet days that has been most of the traffic, so read the device split under each step rather than the total. “Reached the world” fires automatically when the game boots; the first row a player actually causes is “touched the controls”.
